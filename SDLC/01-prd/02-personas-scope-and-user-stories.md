## 1. المستخدمون المستهدفون (Personas)

تعكس هذه الشخصيات الاستخدامَ المؤسسيَّ المتنوع لـ OmniRAG. كل شخصية تحوي **قدرات** و**مؤشرات ألم** و**نتيجة مرجوة** قابلة للقياس تُغذّي قصص المستخدم التالية.

### 1.1 بطاقة ملخص الشخصيات

| الرمز | الاسم والوصف | الدور التنظيمي | الحجم التقريبي للبيانات | الحساسية | النتيجة المرجوة الأساسية |
|---|---|---|---|---|---|
| **P1** | **سامي — الباحث القانوني** يدير مستودع عقود وقرارات تحكيمية بالعربية والإنجليزية | مستشار قانوني أول / رئيس قسم | 5–50 GB، ~10K مستند | **HIPA/GDPR** | استرجاع سياقي دقيق في <3 ثوانٍ مع مراجع قابلة للنقر |
| **P2** | **ليلى — مهندسة DevOps** تربط OmniRAG بمستودعات GitHub وJira وقواعد بيانات التشغيل | SRE / مهندس منصات | 100GB+ سجلات ومستندات تقنية | **PCI** (سجلات بنية تحتية) | تحويل بيانات متفرقة إلى قاعدة معرفية قابلة للاستعلام في وضع Hybrid |
| **P3** | **أحمد — مدير المعرفة المؤسسية** يقود الحوكمة والصلاحيات والامتثال داخل مؤسسة كبيرة | مدير Knowledge Management | 1TB+، آلاف المستخدمين ضمن نفس العقد | **GDPR/HIPA/PCI** | لوحة تحكم إدارية مع تدقيق شامل وعزل تام بين فرق العمل |
| **P4** | **نور — الصحفية الاستقصائية** تُفهرس أرشيفاً من مقاطع فيديو وملفات صوتية ومستندات | صحفية مستقلة/استقصائية | 50–200 GB، وسائط متعددة | **GDPR** | استخراج نص من ملفات الفيديو/الصوت وتلخيص متعدد الوسائط بدقة |
| **P5** | **يوسف — مطوّر Solo/Bootstrap** يستخدم OmniRAG لـ SaaS خاص به ويتكامل معه عبر API | مطوّر مستقل | 1–10 GB، بيانات تطبيقه | **PCI** إن كان تطبيقه ماليًّا | Embed Widget في موقعه + API بسيط + تكامل Zapier MCP |
| **P6** | **فاطمة — المحللة المالية** تحلل تقارير فصلية متعددة وتنشئ موجزات تنفيذية | محللة BI / CFO مساعد | 10–50 GB، PDF معقدة | **PCI/HIPA** | تلخيص مقارن وتحليل جداول متعددة عبر وضع التحليل |

> **القيد المعماري**: كل شخصية ترى **فقاعة بيانات معزولة** (Tenant Bubble). حتى ضمن عقد المؤسسة الواحد (P3)، لا يمكن لأي مستخدم الوصول لبيانات مستخدم آخر — انظر القسم 7 من وصف المنتج.

## 2. نطاق المنتج (Scope)

### 2.1 ما هو داخل النطاق (In-Scope) — النسخة 1.0

| الفئة | القدرات |
|---|---|
| **المصادقة والحسابات** | بريد/كلمة مرور، OAuth (Google, GitHub)، MFA اختياري، تجديد JWT، تصدير وحذف البيانات وفق GDPR |
| **استيعاب البيانات** | ملفات (PDF, DOCX, XLSX, PPTX, CSV, TXT, MD, EPUB, JSON, XML, HTML) + صور + صوت + فيديو + روابط URL + RSS/Atom + YouTube + GitHub + Notion + Google Drive + Confluence + Slack + Gmail IMAP + PostgreSQL/MySQL/MongoDB خارجية |
| **معالجة المستندات** | Mistral DocAI OCR4، Unstructured Transform API، معالج داخلي للنصوص البسيطة، اختيار تلقائي حسب النوع |
| **قاعدة المعرفة** | Collections متعددة، تقسيم ذكي (256–2048 رمز، تداخل 0–30%)، تضمين بـ `gemini-embedding-2` (3072-dim)، تخزين مزدوج في Qdrant + Neon Postgres |
| **البحث** | دلالي + معجمي + Reciprocal Rank Fusion، Cross-Encoder Reranking، MMR، HyDE Query Expansion، بحث عبر اللغات |
| **المحادثة** | 4 أوضاع (Private / Hybrid / General / Analysis)، ذاكرة محادثة قصيرة وطويلة، اقتباسات مع روابط، Streaming، تصدير PDF/Markdown |
| **التكاملات وMCP** | MCP Gateway v2.0 (مواصفة 2026-07-28 عديمة الحالة)، OAuth 2.0 + RFC 8707 + RFC 9207، سجل 8 خوادم MCP مدمجة (Notion, GitHub, Google Drive, Slack, Confluence, PostgreSQL, Qdrant, Firecrawl) + Zapier (8000+ تطبيق) |
| **الأمان والامتثال** | Row-Level Security، Tenant Isolation بثلاث طبقات، تشفير AES-256، TLS 1.3، Rate Limiting، Audit Log |
| **التحليلات** | استعلامات شائعة، Recall@K/MRR/NDCG، زمن الاستجابة لكل مرحلة، تتبّع التكاليف، ملاحظات 👍/👎 |
| **API والتضمين** | REST API v1، API Keys مع Scoping، Webhooks، Embed Widget، SDKs (JS/Python) |
| **اللغة** | ثنائي اللغة عربي/إنجليزي بعمق في كل طبقة، RTL كامل، تطبيع النص العربي، Cross-Lingual Retrieval |

### 2.2 ما هو خارج النطاق (Out-of-Scope) — النسخة 1.0

| الفئة | الاستثناء | التبرير | النسخة المستهدفة |
|---|---|---|---|
| **النماذج المحلية (Local LLMs)** | لا نشر لـ Ollama/LM Studio في Vercel | قيود بنية Serverless | 1.1 |
| **التطبيقات المحمولة الأصلية** | الويب فقط (Responsive PWA) | نطاق MVP | 1.2 |
| **التعاون متعدد المستخدمين في نفس الجلسة** | محادثة فردية لكل مستخدم | تعقيد CRDT/OT | 2.0 |
| **الفوترة والتسعير** | لا طبقة Billing في 1.0 | نطاق MVP | 1.1 |
| **A2A Protocol (Agent-to-Agent)** | تكامل وكلاء خارجيين مستقلين | جديد في 2026 | 1.2 |
| **Fine-Tuning مخصص للنماذج** | استخدام النماذج العامة فقط | تكلفة وتعقيد | 2.0 |
| **OCR لوحات مفاتيح غير قياسية** | دعم 170 لغة افتراضياً فقط | تغطية | 1.1 |
| **وضع Self-Hosted** | استضافة Vercel فقط | قيد MVP | 1.1 |
| **Federated Search بين مؤسسات** | لا تجميع بين عملاء مختلفين | خصوصية | 2.0 |

### 2.3 الافتراضات والقيود

- ✅ بنية تحتية **Serverless بالكامل** على Vercel
- ✅ تكامل مع **Qdrant Cloud** و**Neon Serverless Postgres**
- ✅ الالتزام بـ **GDPR + HIPA + PCI** منذ اليوم الأول
- ✅ دعم **Edge Functions** لزمن استجابة <200ms للبحث
- ⚠️ حدود شهرية افتراضية: 10K استعلام/مستخدم، 100GB تخزين/مستخدم (قابلة للتعديل في 1.1)
- ⚠️ نوافذ سياق النماذج: 1M لـ `gemini-3.6-flash`، 8K عملي لـ `gemini-3.5-flash-lite`

### EPIC A: المصادقة والحساب (Auth & Account)

#### US-A-01 — تسجيل حساب جديد مع إنشاء مساحة عمل معزولة
**بصفتُ** P1/P2/P3، **أريد** تسجيل حساب جديد ببريدي وتأكيده، **حتى** أحصل على مساحة عمل (`tenant_id`) معزولة تلقائياً وجاهزة للاستخدام خلال أقل من 60 ثانية.

| معيار القبول | التحقق |
|---|---|
| إنشاء حساب عبر Email/Password يستجيب بـ HTTP 200 خلال <500ms | اختبار أداء |
| تأكيد البريد عبر رابط مُوقّع بـ JWT صالح لـ 24 ساعة | اختبار وحدة |
| إنشاء `tenant_id` فريد وتفعيل Row-Level Security فوراً | اختبار تكامل |
| إنشاء مجموعة Qdrant افتراضية مع فلتر `tenant_id` إلزامي | اختبار تكامل |
| رسالة خطأ واضحة عند تكرار البريد أو كلمة مرور ضعيفة | اختبار E2E |
| لوحة التحكم تفتح مباشرة بعد التأكيد مع رسالة ترحيب | اختبار E2E |

#### US-A-02 — تسجيل الدخول عبر OAuth مع ربط Tenant تلقائي
**بصفتُ** P5، **أريد** تسجيل الدخول بنقرة عبر GitHub، **حتى** أبدأ فوراً دون إنشاء كلمة مرور.

| معيار القبول | التحقق |
|---|---|
| تدفق OAuth 2.0 ناجح في <3 ثوانٍ مع `state` و`nonce` صالحة | اختبار وحدة |
| ربط `oauth_id` بـ `user_id` بشكل آمن | اختبار تكامل |
| استرجاع `tenant_id` أو إنشاؤه عند أول دخول | اختبار تكامل |
| تسجيل كل عملية دخول في `audit_log` | اختبار وحدة |

#### US-A-03 — إعداد MFA اختياري
**بصفتُ** P3، **أريد** تفعيل المصادقة الثنائية TOTP، **حتى** أحمي بيانات حساسة لـ PCI.

| معيار القبول | التحقق |
|---|---|
| QR Code صالح يتوافق مع Google Authenticator و1Password | اختبار E2E |
| رمز TOTP صالح يُقبل، رمز منتهي الصلاحية يُرفض | اختبار وحدة |
| رموز احتياطية (10 رموز) تُعرض مرة واحدة فقط | اختبار E2E |
| تعطيل MFA يتطلب تأكيد كلمة المرور | اختبار E2E |

#### US-A-04 — تصدير جميع بياناتي (GDPR Article 20)
**بصفتُ** P4، **أريد** تنزيل نسخة كاملة من بياناتي، **حتى** ألتزم بحقوقي تحت GDPR.

| معيار القبول | التحقق |
|---|---|
| طلب التصدير يُنفذ خلال <10 دقائق لـ 50GB | اختبار أداء |
| الملف المُولّد يتضمن JSON لـ metadata + ZIP لـ الملفات الأصلية + Markdown للمحادثات | اختبار E2E |
| رابط التنزيل صالح لـ 7 أيام ومُوقّع | اختبار وحدة |
| جميع التضمينات والمحادثات والوثائق مُضمّنة | اختبار E2E |

#### US-A-05 — حذف الحساب نهائياً (GDPR Article 17)
**بصفتُ** P4، **أريد** حذف حسابي وكل بياناتي، **حتى** أحذف أي أثر من النظام.

| معيار القبول | التحقق |
|---|---|
| تأكيد الحذف يتطلب إعادة إدخال كلمة المرور | اختبار E2E |
| تأخير Grace Period قابل للضبط (0/7/30 يوم) قبل التنفيذ الفعلي | اختبار وحدة |
| بعد التنفيذ: لا استعلام في Qdrant/Postgres يُرجع أي نقطة بيانات | اختبار E2E |
| Audit Log للحذف يبقى للأغراض القانونية | اختبار تكامل |

### EPIC C: البحث والاسترجاع (Retrieval)

| معيار القبول | التحقق |

#### US-C-02 — بحث Cross-Lingual

#### US-C-03 — Cross-Encoder Reranking
**بصفتُ** P1، **أريد** إعادة ترتيب أكثر دقة لأفضل 10 نتائج، **حتى** أحصل على السياق الأكثر صلة.

| معيار القبول | التحقق |
|---|---|

| **NFR-05** | **بصفتُ** مستخدماً عربياً، **أريد** RTL ودعم كامل، **حتى** تكون التجربة طبيعية | اختبار E2E لـ RTL؛ تقييم لغوي لـ 50 استعلام عربي |
| **NFR-06** | **بصفتُ** مؤسسة، **أريد** تشفير البيانات، **حتى** أحمي بياناتي | AES-256 at-rest, TLS 1.3 in-transit |
| **NFR-07** | **بصفتُ** مستخدماً، **أريد** تكلفة منخفضة، **حتى** أستخدم النظام اقتصادياً | Smart Routing يخفض التكلفة ≥40% مقارنة بالنموذج الأحادي |

## 8. ملخص تنفيذي

- **9 Epics**، **47 قصة** قابلة للتنفيذ، و**7 NFRs** كقصص قابلة للقياس.
- تغطية كاملة لـ **جميع** القدرات في وصف المنتج الأصلي.
- كل قصة تربط بـ **معمارية واضحة** و**اختبارات قابلة للتحقق**، مما يمكّن الوكلاء الذكيين من العمل في وضع **Conductor** مع **Orchestrator** لوحدات بحجم Agent.

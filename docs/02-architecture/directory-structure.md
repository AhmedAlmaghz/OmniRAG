# بنية المجلدات

هذه خريطة شجرة المشروع كما هي فعلياً في المستودع، مع وظيفة كل مجموعة ملفات. الإدخالات مستخرجة بقائمة المجلدات الحقيقية.

---

## الجذر

| الملف/المجلد                                                                      | الوظيفة                                                                                                                                                              |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `package.json`                                                                    | البيانات الوصفية والسكربتات (dev/build/start/test/db:*/lint/format — مفصلة في [دليل التثبيت](../01-getting-started/installation.md))                                 |
| `dev-server.js`                                                                   | غلاف خادم التطوير: يقتل `next-server` القديم، يفك `--port`/`--host`، ويشغّل `next dev`                                                                               |

| `Dockerfile` / `docker-compose.yml`                                               | صورة إنتاج متعددة المراحل + مجموعة كاملة (app + postgres + qdrant)                                                                                                   |

| `ara.traineddata` / `eng.traineddata`                                             | نماذج Tesseract OCR للعربية والإنجليزية (تُدمج في صورة Docker)                                                                                                       |
| `drizzle/`                                                                        | التهجيرات: `0000_baseline_unified.sql` (baseline موحد) + `meta/`                                                                                                     |
| `scripts/`                                                                        | `manual-migration.sql` (سكربت تهجير idempotent لـ 25 جدولاً) و`run-manual-migration.ts` (منفذ بلا psql)                                                              |
| `public/`                                                                         | `icon.svg` وسكربتات Unstructured المساعدة (`create_unstructured_job.sh`، `poll_unstructured_job.sh`، `download_unstructured_results.sh`، `unstructured_pipeline.sh`) |
| `vitest.config.ts` / `eslint.config.mjs` / `postcss.config.mjs` / `tsconfig.json` | إعدادات الاختبار والفحص والتنسيق                                                                                                                                     |
| `seed_patch.cjs`                                                                  | رقعة بذر البيانات الأولية                                                                                                                                            |

## `src/app` — طبقة المسارات (App Router)

```
src/app/
├── (workspace)/          # مجموعة مساحة العمل: analytics, chat, knowledge, mcp, settings + layout.tsx + loading.tsx
├── api/
│   ├── health/           # فحص حيوية خفيف (لا يجري round-trip لقاعدة البيانات) — يستخدمه HEALTHCHECK في Dockerfile
│   ├── docs/ genai/ mcp/ sdlc-analyze/
│   └── v1/               # الواجهة البرمجية العامة
├── auth/page.tsx         # شاشة المصادقة (تسجيل/دخول — نموذج محلي على PostgreSQL)
├── layout.tsx            # الجذر — يستلم nonce الـ CSP من الوسيط عبر x-csp-nonce
├── page.tsx              # الصفحة الرئيسية (LandingPage / ClientHome)
├── error.tsx / global-error.tsx / not-found.tsx / globals.css
```

أهم مسارات `src/app/api/v1`:

| المجلد                                                                                                                                  | الوظيفة                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `chat/stream` و `chat/completions`                                                                                                      | محرك المحادثة: بث SSE بروتوكول AI SDK UI-message، واستكمال تقليدي — كلاهما RAG هجين + أدوات MCP                                     |
| `documents/`                                                                                                                            | CRUD المستندات + `parse` (استخراج/OCR)، `upload-session`/`upload-token` (رفع مباشر S3/Blob)، `versions`، `status`، `web-fetch`      |
| `collections` / `sources`                                                                                                               | المجموعات المعرفية وموصلات المصادر الحية (url/rss/github/youtube/file)                                                              |
| `conversations`                                                                                                                         | جلسات المحادثة المحفوظة في PostgreSQL                                                                                               |
| `search`                                                                                                                                | نقطة بحث مستقلة فوق محرك RAG الهجين                                                                                                 |
| `auth/` (login, register, logout, session, sso, workspaces)                                                                             | المصادقة والجلسات وSSO وإدارة مساحات العمل                                                                                          |
| `members`, `teams`, `invitations`, `plan`, `providers`, `api-keys`                                                                      | إدارة العضويات والفرق والدعوات وخطط العملاء ومفاتيح المزودين ومفاتيح API                                                            |
| `mcp/` (servers, calls, oauth, presets, health, generate-tool)                                                                          | إدارة سيرفرات MCP وتنفيذ الأدوات وOAuth                                                                                             |
| `jobs/tick`                                                                                                                             | مشغّل مهام الخلفية (Vercel Cron) المحمي بـ `CRON_SECRET`                                                                            |
| `webhooks`, `env-config`, `analytics`, `storage`, `settings`, `shares`/`share`, `files`, `youtube`, `pipeline-templates`, `diagnostics` | Webhooks الصادرة، إدارة البيئة الديناميكية، الإحصاءات، التخزين، الإعدادات، المشاركة، الملفات، يوتيوب، قوالب خطوط الاستخراج، التشخيص |

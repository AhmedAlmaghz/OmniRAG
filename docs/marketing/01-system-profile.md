## التعريف المرن (Elevator Pitch)

**OmniRAG** هي منصة استرجاع معزَّز بالتوليد (RAG) من الطراز المؤسسي، صُممت لتقوم المؤسسات العربية والعالمية ببناء مساعداتها المعرفية الرسمية عليها: ترفع مستنداتك ومصادرك المعرفية (PDF، Word، صفحات الويب، GitHub، أخبار RSS، فيديوهات YouTube...)، فيقطعها النظام بدقة ويضمّنها متجهياً، ويمزج البحث المتجهي بالبحث المعجمي عبر دمج **RRF** — فيجيب موظفوك وعملاؤك بدقة عالية **مع استشهادات صفحة-بصفحة**، وبعزل تام بين المستأجرين، وحماية طبقية تشمل التحقق من الحقن (Injection Shield) وحجب البيانات الشخصية (PII) وحدود المعدل وضوابط SSRF — جاهزاً للنشر على أي سحابة أو خادم خاص.

## 💎 المميزات المحورية (10 الركائز)

### 1. محرك RAG هجين فائق الدقة

- بحث متجهي كثيف (Dense Vector) + بحث معجمي نصي كامل (FTS/lexical) في وقت واحد.
- دمج النتائج بخوارزمية **Reciprocal Rank Fusion (RRF)** بأوزان مضبوطة (متجهي/معجمي).
- كواشف الاستعلامات التجميعية (Aggregative Detector) لضمان تغطية المستند كاملاً عند الحاجة.
- حارس تقادم المتجهات وجولات استرجاع متعددة بحدود سياق ذكية (`CONTEXT_CHUNK_CAP`).

### 2. دعم اللغة العربية من الطراز الأول

- **تطبيع عربي موحد** للتضمينات (Arabic Normalization) يعالج الهمزات والتاء المربوطة والتشكيل.
- فهارس بحث نصي GIN للعربية والإنجليزية معاً في PostgreSQL.
- واجهة RTL كاملة، ودعم رياضيات عبر `katex4arabic`.

### 3. استشهادات موثوقة صفحة-بصفحة

- كل إجابة مزودة بالمصادر الدقيقة من المستند الأصلي.
- عارض استشهادات مدمج، وتتبع نسخ المستندات (versions) وإعادة فهرستها.

### 4. درع أمني متعدد الطبقات (Enterprise Guardrails)

- **Injection Shield** — يفحص المستندات واستعلامات المستخدم ضد هجمات الحقن المباشر وغير المباشر قبل النموذج.
- **SSRF Guard** — قائمة نطاقات/عناوين خاصة محظورة، تثبيت DNS، مهلة وسقف حجم على كل طلب صادر.
- **PII Redaction** — تدفق الإجابات يُنقت لحظياً من البيانات الشخصية.
- تشفير اعتمادات الموصلات وWebhooks بـ **AES-256-GCM**؛ كلمات المرور بـ **Argon2id**.
- سجل أحداث أمني جذري (`audit_logs` — H12) وحدود معدل دائمة (`rate_limit_windows`).

### 5. منصة مستأجرين حقيقية (Multi-Tenancy)

- عزل بيانات كامل: كل جدول، كل استعلام، كل قفل أمان محكوم بـ `tenantId`.
- فرق، أدوار، وصلاحيات، دعوات، ومشاركة موارد مؤقتة بروابط مؤمنة.
- تسجيل دخول موحّد (SSO OIDC مع PKCE S256 وRS256 JWKS).
- مفاتيح API مستقلة لكل تكامل مع أذونات منفصلة عن جلسات المستخدمين.

### 6. تغذية معرفية حيّة من كل مكان

- موصلات فعلية جاهزة اليوم: صفحات الويب، RSS/Atom، GitHub (README + بيانات وصفية)، YouTube (تفريغ نصي حقيقي)، ملفات (PDF/Word/TXT/JSON/CSV/صوت عبر Groq Whisper).
- محرك استخلاص OCR متعدد المحركات: Mistral Document AI، **Tesseract.js محلي بالكامل** (العربية والإنجليزية بدون اتصال)، pdf-parse، Unstructured (الجيلان الحديث والقديم).
- مزامنة مجدولة خلفية (pg-boss / Vercel Cron) تبقي المعرفة محدثة تلقائياً.

### 7. RAG وكيلي عبر MCP (Agentic)

- الاتصال بسيرفرات MCP الخارجية مع OAuth مشفّر، اختبار الاتصال، وتوليد أدوات ديناميكي.
- آلة بحث حي داخلية (`web_live_search` عبر Tavily/Serper/Brave) مع تدهور صادق عند غياب المفاتيح.
- موافقة المستخدم قبل تنفيذ الأدوات (Side-effect confirmation).

### 8. واجهة استوديو احترافية متعددة الأقسام

- **استوديو المحادثة:** بث حي، اقتراحات متابعة، متصفح الأسئلة، لوحة الاستشهادات، تصدير الجلسات.
- **قاعدة المعرفة:** بطاقات مستندات، مفتش الشرائح، معاينة، سجل الإصدارات، تشخيص الصحة الحي.
- **التحليلات:** لوحات مؤشرات، مخططات، تتبع تدقيقي أمني، مختبر بحث هجين.
- **الإعدادات:** مزودو النماذج، النماذج وإعادة التضمين الإجبارية، خطط الاستيعاب، الأعضاء، مفاتيح API، SSO، التخزين، متغيرات البيئة، الخطط.

### 9. مرونة النشر والقابلية للتطوير

- توزيعة واحدة تعمل على Vercel، Docker، أي Kubernetes/VPS.
- PostgreSQL + Qdrant (أو pgvector) خلف واجهات Database Adapters قابلة للتبديل.
- رفع كبير مباشر إلى S3/Blob يتجاوز حدود المنصات.

### 10. قابلية التشغيل العملياتي الكامل

- `/api/health` liveness و`/api/v1/diagnostics` (**probes فعلية** لـ PostgreSQL/Qdrant/Mistral مع قناع أسرار).
- تهجير قاعدة موحد وبذر أولي تلقائي عند الإقلاع.
- خطّافات تحقّق متسلسلة (H1…H12) عبر `hook-harness` — كل التزام صارم قابل للاختبار الوحدي في CI.

## 📊 مؤشرات الجاهزية المؤسسية

- **أمان:** يمر التطبيق بنشر الإنتاج فقط عند استيفاء المتغيرات الإلزامية (`DATABASE_URL`، `MCP_OAUTH_ENCRYPTION_KEY`، `CRON_SECRET`).
- **مراقبة:** تشخيص صحي حقيقي للمكونات الحيوية مع درجة readiness (healthy/degraded/critical) — لا حصيلة «100%» مزيّفة.
- **اختبارات:** اختبارات فيتري (coverage من المحاور الحرجة بما فيها SSRF والحقن وPII والجلسات ومفاتيح API).
- **توثيق:** 9 أقسام توثيق مرجعية (v0.12.x) مبنية على قراءة الكود الفعلي.

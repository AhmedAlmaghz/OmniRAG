## 🎯 مبادئ استخدام الحزمة

1. **الصدق التسويقي:** كل ادعاء في هذه الحزمة مرتبط بميزة موثّقة في الكود. عند إضافة ميزة جديدة، حدّث `docs/` أولاً ثم هذه الحزمة.
2. **الهوية الموحدة:** استخدم الاسم «OmniRAG» كما هو، والوصف القصير المعتمد: «منصة RAG مؤسسية متكاملة — معرفتك، بذكاء اصطناعي موثوق قابل للاستشهاد».
3. **الأسواق المستهدفة:** العربية أولاً (تفوّق في دعم العربية مقابل المنافسين)، ثم الإنجليزية.
4. **عدم رفع أسرار:** لا تحتوي هذه الملفات على أي مفاتيح أو بيانات حساسة — حافظ على ذلك.
